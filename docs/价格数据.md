# 价格数据（2026-11 人工浏览）

## 闲鱼：修图接单商品

- 挂价集中在 **1–10 元**，大量 **1 元**引流价（「累计降价 88%」），实际价格在商品标题或私聊里。
- 标题中写明的价格：「接日常/cos 后期 p 图修图，**10r 一张**」「高 p 修图精修，**25 元一张**」。
- 卖点用语：「拒绝一眼假」「保持自身自然感不假」「不是一键美颜」「秒回」「不满意退全款」。

## 观察

1. **个人 / 学生接单市场价格极低且透明度差**：挂价多为 1 元引流价，真实价格要私聊。
2. **预期不一致的风险由卖家承担**：「满意后再付钱」「初稿不满意不收费」已经成为主要竞争手段。卖家用「免费重做」来对冲需求说不清的风险。需求单的价值正是降低这部分成本：对卖家来说是减少白干，对买家来说是减少反复沟通。
3. **卖家也在回应「反 AI 感」**：「不是一键美颜」「拒绝一眼假」。

`lib/pricing.js` 的报价区间据此更新：修图日常 5–20 元/张、精修/高 p 10–50 元/张；剪辑按时长分档 5–100 元（个人/学生接单价）。
