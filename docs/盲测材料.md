# 服务方盲测材料

> 目的：验证 BriefAI 生成的需求单对**真实接单的修图师 / 剪辑师**是否有用。这是目前所有评测都是模拟数据的唯一补充。

## 怎么做（付费咨询，每人 3 元）

1. 在小红书或闲鱼找 **5 位正在接单的修图师**、**5 位正在接单的剪辑师**（搜「接单 修图」「p 图接单」「剪辑接单」「代剪」）。
2. **第一条私信只发一句**（话术 1），说清楚「付费、占用多久」，先不发材料。
3. 对方同意后，**先转 3 元**，再发话术 2 和对应的材料。
4. 每人只发 **1 组**材料，按下面的分配发：
   - 修图师：材料 1 → 第 1、4 位，材料 2 → 第 2、5 位，材料 3 → 第 3 位
   - 剪辑师：材料 4 → 第 1、4 位，材料 5 → 第 2、5 位，材料 6 → 第 3 位
5. 对方回复后截图，或者把回答填进最后的记录表。也记下**私信了多少人、多少人同意**，回复率本身也是数据。
6. 尽量找**不同价位**的人（白菜价的学生、几十元一张的专业修图师）。
7. **不要假装成客户**：付费咨询本身就是真实的服务交易，不需要编造下单需求。

## 话术 1：第一条私信（只发这一句）

```
你好～想付费请你帮忙看一份修图需求单，给点专业意见，大概 3 分钟，3 元先转你，方便吗？
```

剪辑师把「修图」改成「剪辑」。

## 话术 2：对方同意、转账之后

```
谢谢！我在做一个帮客户把修图需求写清楚的小工具（求职作品）。下面 A 是客户原帖，B 是工具整理出来的需求单，想听听你的意见：

1. 如果你接这单，更想收到 A 还是 B？为什么？
2. 拿到 B 能直接开工吗？打个分（1–5 分），还缺什么？
3. B 里有没有写得太细、你觉得没必要或者做不到的？

A：（原帖）
B：（需求单）
```

> 说明：需求单 B 是根据原帖，由工具与模拟客户对话后生成的，所以包含原帖之外的信息。这正是工具要做的事：把没说清楚的问出来。如果对方问起，如实说明即可。

> 已知情况：部分需求单写得很细（例如材料 4、5 里的具体音量、色温要求），这些是 AI 补充的。第 3 个问题正是要看服务方怎么评价这类细节。

## 材料 1（R03，发给修图师）

**A：客户原帖**

> 求超自然日常P图 就是那种日常随便拍，需要微调，可以认出本人的，不要厚涂浓妆，质量高，价格可加，求无排单 不钓鱼，带例图来

**B：BriefAI 需求单**

- **照片数量与类型**：1张，手机原图，无路人无杂物
- **用途与发布场景**：朋友圈、小红书日常分享
- **需要修的地方**：皮肤瑕疵、光线调整
- **修图程度**：自然微调
- **风格与色调**：超自然日常
- **不能改动的地方**：脸型、痣、发型、本人辨识度
- **截止时间**：1周内
- **修改次数**：1-2次
- **验收标准**：熟人一眼认出是我；皮肤有真实纹理，无塑料感或假面感；肤色自然暖调，不冷白不发灰；无液化/眼妆增强/滤镜叠加

**风格要求说明**
- 「超自然日常」→ 皮肤保留真实纹理与毛孔，仅局部祛痘/泛红/黑眼圈；亮度提升但不过曝，对比度柔和；肤色校正至自然暖调（非冷白），不改变唇色/眼周/腮红原有状态；零液化、零眼妆增强、零滤镜叠加
- 「微调」→ 单张处理时间约8–15分钟，聚焦瑕疵修正与光影平衡，不做结构级调整
- 「能认出本人」→ 家人/熟人一眼可确认身份，五官比例、神态、面部特征（如痣、卧蚕、法令纹走向）100%保留

## 材料 2（R09，发给修图师）

**A：客户原帖**

> 有偿找 p 图 价格不要太贵 喜欢那种原生感的 p 图 不要太假不要 AI 感的 有合适的宝子滴滴我 o(^▽^)o

**B：BriefAI 需求单**

- **照片数量与类型**：1张自拍照
- **用途与发布场景**：朋友圈
- **需要修的地方**：脸上的痘痘和黑眼圈
- **修图程度**：自然微调
- **风格与色调**：原生感
- **不能改动的地方**：发型、眼睛颜色
- **截止时间**：3天内
- **预算**：100元以内
- **验收标准**：皮肤保留真实纹理与毛孔，无塑料感；修后家人朋友一眼认得出是我；痘痘/黑眼圈淡化自然，不改变本人神态与五官比例

**风格要求说明**
- 「原生感」→ 几乎看不出修图痕迹，仅处理明显瑕疵（如痘痘、泛红、杂乱发丝），肤色均匀但保留纹理与毛孔，不液化脸型/五官，不改变本人神态和骨相特征
- 「不要太假、不要AI感」→ 禁用一键美颜模板、禁用塑料感磨皮、禁用失真瘦脸/大眼/尖下巴算法；所有调整需肉眼难察觉，修完家人朋友能一眼认出是你

## 材料 3（R10，发给修图师）

**A：客户原帖**

> 有偿找p图 想找一个长期p图的老师 想要保留个人特征自然一点的 不要太假 五官需要协

**B：BriefAI 需求单**

- **照片数量与类型**：1张，手机自拍
- **用途与发布场景**：小红书/朋友圈日常分享
- **需要修的地方**：五官协调
- **修图程度**：自然微调
- **风格与色调**：保留个人特征、自然不假
- **不能改动的地方**：个人特征（如脸型、痣、发型等）
- **截止时间**：1周内
- **验收标准**：家人朋友一眼认得出是我；皮肤保留真实纹理，不磨成塑料感；脸型线条自然，不做液化瘦脸

**风格要求说明**
- 「自然一点」→ 皮肤保留真实纹理，不磨皮过度；不做液化大改脸型；肤色均匀但不提亮过曝；五官调整以比例协调为主，不改变原生结构（如双眼皮宽度、鼻梁走向、唇形轮廓）
- 「五官需要协调」→ 通过微调眼距、鼻宽/鼻长比、唇眼比例、下颌角线条等，使面部整体更和谐；不追求‘标准三庭五眼’，而以本人原有基础为基准做适度平衡

## 材料 4（V01，发给剪辑师）

**A：客户原帖**

> 旅行vlog剪辑有没有！如图，跟家人出去玩拍了好多乱七八糟的视频照片，本来想着回来以后好好剪辑一下，结果是发现又没有时间又没有技术，一看这么多东西，人都麻了，静不下心来😂 想付费请人帮忙剪一下，有没有愿意接单的呀😂 请带价联系一下 没啥要求，就是做出故事感，把有意义的剪进去，时长和交稿时间都没有硬性要求，就是自己家人看，也不用发网上要爆款啥的，就希望能看出来用心就可以了。

**B：BriefAI 需求单**

- **素材情况**：横屏为主，含视频与照片，>30段，总时长>90分钟
- **叙事与内容重点**：突出旅途中的欢笑互动，聚焦家人之间的温馨时刻与有趣瞬间
- **用途与发布平台**：家人内部观看、留存纪念
- **成片时长与画幅**：6–10分钟，横屏，单条完整成片
- **风格与节奏**：故事感、用心感（非网感/爆款）
- **BGM / 字幕 / 文案**：轻音乐或旅行主题纯音乐；字幕按需添加（简洁白字）
- **验收标准**：家人看完第一反应是：‘原来我们玩得这么开心！’；画面中必须包含爸妈海边散步、全家海鲜大餐两个核心场景；整体节奏有起承转合，不流水账

**风格要求说明**
- 「故事感」→ 有清晰的时间线或情绪线（如出发→抵达→欢笑时刻→温馨结尾），避免流水账；用镜头顺序和节奏营造起承转合
- 「用心感」→ 手工调色（不套滤镜模板）、关键画面加轻微动态（如缩放/慢动作）、字幕手写体或柔和字体、BGM音量随人声自然起伏

## 材料 5（V03，发给剪辑师）

**A：客户原帖**

> 旅游视频求代剪 自己去日本玩的素材 大疆action5pro拍摄 总素材量一两个小时左右 想剪条有故事感氛围感的vlog 时长半小时内可长可短 求各位剪刀手滴滴，可练手用 非商用大佬价高勿扰谢谢

**B：BriefAI 需求单**

- **素材情况**：大疆 Action 5 Pro 拍摄，总时长约 1–2 小时
- **叙事与内容重点**：通过镜头顺序、人物动线、环境空镜衔接，让人看懂‘我在哪里、做了什么、心情如何’，比如：地铁进站→抬头看路牌→走出站台拍樱花→笑着咬一口章鱼烧
- **用途与发布平台**：个人留念，发布于朋友圈 / 小红书
- **成片时长与画幅**：≤30 分钟，时长可灵活调整
- **风格与节奏**：温馨、旅行感强，舒缓叙事型：每个镜头停留3–5秒，多用空镜转场（如电车窗外掠过的樱花→你笑着抬头→咬一口章鱼烧），配轻柔吉他+BGM淡入淡出，字幕出现慢、停留久
- **BGM / 字幕 / 文案**：需要轻快愉悦的旅行风BGM + 简洁中文字幕
- **截止时间**：2周内
- **验收标准**：家人朋友一眼认出是你，表情/神态/发型/衣着完全真实，不P脸、不液化脸型、所有景点/美食/街景画面都保留现场真实光影（如阴天的灰调、傍晚暖光），不强行提亮或加滤镜、字幕只出现在画面空白处（如底部黑条/角落），字体简洁无装饰，字号适中不遮挡重点

**风格要求说明**
- 「故事感」→ 通过镜头顺序、人物动线、环境空镜衔接，让人看懂‘我在哪里、做了什么、心情如何’，比如：地铁进站→抬头看路牌→走出站台拍樱花→笑着咬一口章鱼烧
- 「氛围感」→ 保留现场环境声（如市井人声、列车报站、鸟鸣），搭配舒缓轻音乐；色调偏暖黄或胶片感，不过度提亮，保留阴天/傍晚的真实光影层次
- 「温馨、旅行感强」→ 色彩以暖黄/浅棕为主调，避免冷蓝；多用中近景捕捉表情与互动（如你和店员对视笑、手捧热茶哈气）；BGM选用带口琴、尤克里里或轻快钢琴的纯音乐，音量控制在不压过原声人声
- 「节奏不要太快也不要太慢」→ 单镜头平均时长2.5–4秒，避免连续快速切镜；转场以淡入淡出、匹配剪辑（如挥手→下一帧手接咖啡）为主，不用炫技转场
- 「舒缓叙事型」→ 每个镜头停留3–5秒，多用空镜转场（如电车窗外掠过的樱花→你笑着抬头→咬一口章鱼烧），配轻柔吉他+BGM淡入淡出，字幕出现慢、停留久
- 「最不能接受画面太AI感」→ 禁止使用AI一键美颜/过度磨皮/失真液化；皮肤保留纹理与自然阴影，五官比例、脸型、痣、发型等不得改动
- 「最不能接受BGM盖过原声人声」→ BGM全程音量控制在-18dB以下，关键原声（如店员招呼、朋友对话、列车报站）必须清晰可辨

## 材料 6（V04，发给剪辑师）

**A：客户原帖**

> 找代剪 有偿 需要有综艺感的视频 来个经常看综艺的宝子啊！！急急急

**B：BriefAI 需求单**

- **素材情况**：含授权综艺片段 + 自录素材（已备齐）
- **用途与发布平台**：小红书 & 抖音发布
- **成片时长与画幅**：1–2分钟，竖屏
- **风格与节奏**：综艺感
- **BGM / 字幕 / 文案**：需配流行BGM + 搞笑字幕及文字特效
- **封面**：需封面，用视频中最具喜剧效果的一帧
- **截止时间**：一周内

**风格要求说明**
- 「综艺感」→ 节奏明快、多用跳切/音效卡点、动态字幕（如弹幕式、放大强调、表情包贴纸）、人物反应镜头突出、适当加花字/箭头/圈画等引导视线，色调明亮活泼，避免平铺直叙
- 「《奔跑吧》式」→ 高频花字（如‘震惊！’‘突然出现’‘本人否认’等拟声/吐槽类），镜头间插入夸张音效（咚！咻！咔嚓！），人物动作配合闪白/抖动/缩放特效，保留真实感前提下强化戏剧张力
